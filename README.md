# 239 平精装房轻改与全屋定制执行包

这份执行包把当前方案落成可沟通、可报价、可复尺、可验收的装修任务书。默认策略是轻改：保留精装硬装、墙体和原卫浴防水，主要通过全屋定制、成品家具、局部电位、灯光、软装和可逆设备完成。

## 设计目标

- 常住：3-4 人。
- 房间：保留 3 间完整睡眠房，牺牲 1 间卧室做独立半专业健身房。
- 办公：主卧套房内做双人坐站交替办公区，满足中高隐私和视频会议。
- 健身：右下角靠玄关卧室改为龙门架/引体/哑铃训练房。
- 茶位：南向大阳台靠客厅侧做景观独处小茶桌。
- Spa：优先采用成品红外/干蒸桑拿舱，不拆改原卫浴防水。
- 收纳：全屋柜体统一风格，优先解决玄关、家政、餐边、办公、健身和卧室收纳。

| 区域 | 落位 | 功能 | 实施方式 |

| 右下卧室 | 靠玄关卧室 | 半专业力量房 | 龙门架、整屋橡胶地垫、镜墙、哑铃/杠片收纳、通风与门缝降噪 |

## 推荐平面策略

### 1. 健身房优先独立

右下角靠玄关卧室是第一推荐健身房位置。理由是器械从电梯厅进入最短，离次卫近，训练后淋浴动线短，也更容易把噪音控制在公共区边缘。

健身房默认配置：

- 龙门架或小型综合架：含引体、拉索、深蹲/卧推基础功能。
- 可调哑铃或哑铃架：优先节省空间，避免大量散放器械。
- 地面：15-25 mm 橡胶地垫，龙门架下方可局部加厚。
- 墙面：一面镜墙，另一面做浅柜或开放器械架。
- 门窗：门底密封条、厚窗帘或蜂巢帘、训练时强制通风。
- 安全：杠铃活动区、拉索展开区、门扇开启区不可重叠。

### 2. 双人办公放进主卧套房

主卧套房的起居/书房区改为双人办公，不占公共客厅，也能获得较高安静度。两张桌建议并排靠墙或 L 型错位，避免两人视频会议互相入镜。

办公区默认配置：

- 两张电动升降桌，每张满足双显示器、笔记本、键鼠和台灯。
- 每人独立插座位：强电、网口或预留 Mesh/有线回程、桌下理线槽。
- 背景墙：浅色柜体或木饰面，避免杂物暴露。
- 收纳：整墙书柜/文件柜，底部封闭，上部开放或玻璃门。
- 灯光：顶部基础光、桌面重点光、视频会议柔光。
- 声学：厚窗帘、地毯、软包椅或局部吸音画，减少会议回声。

### 3. 茶位做小而精

茶位放在南向大阳台靠客厅侧，不做大茶室。茶桌体量要小，保留阳台门、清洁、通行和可能的晾晒/绿植空间。

茶位默认配置：

- 低茶桌一张，两把单椅或蒲团。
- 300-450 mm 深窄边柜，收纳茶具、烧水壶、杯具。
- 就近预留插座，桌下或柜内做理线。
- 阳台材质注意防晒、防潮、易清洁。

### 4. 桑拿只做可逆方案

轻改阶段不建议把原淋浴间改成蒸汽房，也不建议新增冷水池。优先选择成品红外或干蒸桑拿舱，现场复尺后放在主卧套房干区附近；若不合适，再评估健身房一角。

桑拿落地前必须确认：

- 设备尺寸与入户、入房、转角、门洞搬运路径。
- 电源功率、独立回路、插座位置和安全距离。
- 散热、通风、开门方向和舱外预留活动空间。
- 与木地板、柜体、窗帘、软装的安全距离。
- 不破坏原卫浴防水，不接入复杂排水。

## 全屋定制重点

| 项目 | 核心目标 | 设计要点 |
| --- | --- | --- |
| 玄关柜 | 入户整洁、鞋帽收纳 | 换鞋凳、全身镜、常穿鞋开放格、扫地机器人位 |
| 餐边茶水柜 | 餐厨补充与茶水系统 | 小电器高柜、杯具抽屉、净饮机/咖啡/茶具区 |
| 家政柜 | 清洁效率 | 吸尘器、拖把、洗护用品、囤货分区，预留插座 |
| 办公书柜 | 双人长期办公 | 文件柜、设备柜、打印机位、线缆隐藏、背景整洁 |
| 健身收纳 | 安全和易复位 | 哑铃、杠片、弹力带、瑜伽垫、毛巾和补给品分区 |
| 卧室衣柜 | 保留 3 间卧室能力 | 挂衣优先，抽屉适量，儿童/长辈房留可变空间 |

## 执行顺序

1. 现场复尺：确认净尺寸、层高、门洞、墙体、插座、空调/新风、地暖或楼板条件。
2. 设备先定：先确定龙门架、升降桌、桑拿舱的准确尺寸和电源要求。
3. 平面锁定：用设备真实尺寸反推柜体、插座、灯光和动线。
4. 全屋定制深化：玄关、餐边、家政、办公、健身、卧室柜统一出图报价。
5. 局部电位和灯光：按桌位、茶位、桑拿舱、健身房风扇/空气循环设备补点。
6. 安装顺序：保护精装、局部电位、柜体、设备进场、软装、最终验收。

## 风险边界

- 不拆承重墙，不改外立面，不封阳台前先确认物业规则。
- 不重做全屋水电，不大改卫浴防水。
- 健身房器械承重、冲击噪音和楼板条件必须现场确认。
- 桑拿舱用电必须由合规电工确认，不用插排凑功率。
- 阳台茶位不能影响消防、排水、门窗开启和清洁。
